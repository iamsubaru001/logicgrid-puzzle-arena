# LogicGrid — Interactive Cipher & Deduction Puzzle Arena

A browser-based puzzle web application featuring Caesar cipher decoding challenges, logical sequence deduction riddles, and a persistent local score & rank tracker.

## Team & Project Details
- **Developer:** Anuj (USN: 221 | Section B)
- **Git Workflow:** Feature-branch development (`feature/cipher-decoder`, `feature/sequence-riddles`, `feature/score-tracker`) merged via Pull Requests into `main`.

## Modules
1. **Cipher Decoder (`cipher.html`):** Crack shifted messages and test custom Caesar cipher encodings.
2. **Sequence Riddles (`sequences.html`):** Solve mathematical and logical pattern deduction levels.
3. **Score & Rank Tracker (`leaderboard.html`):** Track solved puzzles and detective ranks stored in `localStorage`.
